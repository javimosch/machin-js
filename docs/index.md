# machin-js

**Write native machin apps in plain JavaScript, readable enough to maintain when the agent is off.**

machin-js turns a strict, JSDoc-typed subset of JavaScript into
[machin](https://github.com/javimosch/machin) code, which compiles to a native binary. It is
**alpha**, with one worked example: a todo app with web and desktop front ends.
