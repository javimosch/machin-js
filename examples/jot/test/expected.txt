== jot guide --human
# jot 0.1.0

A task list that an AI agent or a script can drive. jot keeps tasks in a local SQLite file. Every command is non-interactive and answers with JSON.

## Model

- One local SQLite file: $JOT_DB, default jot.db in the current directory. No server, no network.
- Data goes to stdout as one JSON object with ok and version. --text gives one tab-separated task per line.
- On failure stdout is empty, stderr holds one JSON error object, and the exit code equals error.code.

## Loop

- jot list to see what is open
- jot add <title> for new work
- work on a task
- jot done <id> when it is finished
- jot list again

## Concepts

- task: id, title, tag and done.
- id: A whole number jot assigns. It is never reused, even after rm.
- tag: An optional label. list --tag shows one tag.
- done: A finished task. list hides done tasks unless --all is given.

## Commands

- jot add <title> [--tag <name>]
- jot list [--all] [--tag <name>]
- jot show <id>
- jot done <id>
- jot rm <id>

## About jot

- jot guide [--human]
- jot help-json
- jot version

## Examples

Add a task and read its id:

    jot add "write the report" --tag work
    jot show 1

See what is open for one tag:

    jot list --tag work
    jot list --tag work --text

Finish a task, then see everything:

    jot done 1
    jot list --all

Add a title that starts with a dash:

    jot add -- "-v flag is broken"

## Gotchas

- The database is jot.db in the current directory unless JOT_DB is set, so another directory shows another list.
- done on a finished task fails with 95 already_done; a missing id is 92 not_found.
- Titles and tags are one line. Newlines, tabs and other control characters are refused with 85.
- Flags jot does not know are errors (80), not ignored. Put -- before a title that starts with a dash.
- jot never retries. An error with recoverable true may be retried by the caller.

## See also

- jot help-json
- jot version

exit 0
